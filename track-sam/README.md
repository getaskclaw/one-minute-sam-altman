# Track: Sam Altman 博客金句 · 1 分钟微学习

## 契约（duration contract）

- 每个任务设计为 **≤1 分钟内完成**。
- 没完成的任务下次保持同一个 ID 继续，不重置。
- 无每日打卡要求；进度以完成任务数计。
- 任务数是容量估计，不是期限：这个时长只是说每个动作很小，不是说总时长内能"学完"。

## 结构

```text
track-sam/
├── README.md       # 本文件：说明与导航（不是进度真相源）
├── TASKS.md        # 编号任务 + 复选框

```

## 规则

- 完成任务时，把证据（你的回答）发出来；判定按**语义覆盖**，不要求和原文措辞一致。
- 标 `回忆` 的任务：不看 LESSONS.md / GEMS.md 回答。
- 说"我不懂"会得到解释，解释**不计进度**，任务保持打开。
- 状态：`active` —— 从 SAM-0001 开始，按顺序做。
